# Computational Contribution

## Purpose

This repository contains the computational and experimental
engineering component developed for the REBECA-AR project.

The objective is not to propose a new facial-expression recognition
algorithm.

Instead, the computational contribution investigates the technical
applicability of existing methods for a future Augmented Reality
extension of REBECA.

## Planned contribution

The computational work includes:

1. reproducibility analysis of the EmoAR technical reference;
2. construction of a reproducible facial-expression inference pipeline;
3. standardized quantitative evaluation of candidate models;
4. measurement of computational performance and inference latency;
5. error analysis and visualization;
6. investigation of temporal prediction stability;
7. investigation of confidence-based abstention;
8. external-domain evaluation when suitable authorized data are available;
9. development of a camera-based technical demonstrator;
10. investigation of integration with an Augmented Reality interface.

## Expected research artifacts

The project should produce:

- source code;
- experiment configurations;
- executable notebooks;
- model and dataset manifests;
- quantitative results;
- confusion matrices;
- latency measurements;
- temporal-stability measurements;
- figures for the research paper;
- reproducibility documentation;
- technical methods and results text for the paper.

## Relationship to the main REBECA-AR study

The main study investigates the applicability of Augmented Reality
approaches to REBECA.

This computational component provides empirical technical evidence
that complements the conceptual and literature-based applicability
analysis.

It should therefore be considered an experimental probe of technical
applicability rather than a replacement for the main research scope.

## Authorship traceability

Contributions will be traceable through:

- Git commits;
- experiment notebooks;
- source code;
- generated metrics;
- figures;
- technical documentation;
- Methods and Results material derived from the experiments.

Final authorship and CRediT roles must reflect the contributions
actually performed during the project.
