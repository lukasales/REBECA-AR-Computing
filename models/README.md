# Models

Model weights are not committed directly to this repository.

For every model used, record:

- model name;
- original source;
- repository or model-hub identifier;
- exact revision or commit when available;
- license;
- architecture;
- number of parameters when available;
- expected input preprocessing;
- output classes;
- local modifications, if any.

Experiments must remain traceable to the exact model version used.
